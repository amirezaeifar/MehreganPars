# مهرگان پارس — وب‌سایت مادر و پلتفرم‌های سلامت

رابط فارسی و راست‌به‌چپ با Vue 3، TypeScript و Vite؛ بدون بک‌اند.

## اجرا

- `npm install`
- `npm run dev`
- `npm run build` برای بررسی TypeScript و ساخت خروجی
- `npm run preview` برای پیش‌نمایش خروجی
- `node tests/operations.test.mjs` برای آزمون قواعد رزرو و زمان‌بندی

## مسیرها

- `/`: منظومه متحرک پنج برند و معرفی هولدینگ
- `/platforms/health-center`: مجتمع سلامت مهرگان
- `/platforms/physiopars`: فیزیوپارس
- `/platforms/oncopars`: آنکوپارس
- `/platforms/psychopars`: سایکوپارس
- `/platforms/telenutrition`: تله‌تغذیه
- `/admin`: نمای کلی هولدینگ و صندوق پیام‌های ارتباط با ما
- `/admin/magazine`: ایجاد، ویرایش، انتشار و حذف مقاله‌ها
- `/admin/platforms/:slug`: متخصصان، زمان‌بندی، زمان‌های آزاد و رزروشده و مدیریت نوبت‌های همان برند
- `/magazine` و `/magazine/:slug`: مجله و مقاله‌ها
- `/about` و `/contact`: معرفی و ارتباط با هولدینگ

## آزمایش مسیر کامل

از سایت یک پلتفرم، متخصص و زمان انتخاب کنید و رزرو را ثبت کنید. نوبت همراه نام، تلفن و توضیح در پنل همان پلتفرم نمایش داده می‌شود. با لغو رزرو، زمان دوباره آزاد خواهد شد. زمان رزروشده قابل ویرایش یا مسدودکردن نیست. هم‌پوشانی زمان‌های یک متخصص، رزرو زمان گذشته و رزرو برای متخصص غیرفعال رد می‌شوند.

در صفحه ارتباط با ما یک پیام ثبت کنید؛ از پنل هولدینگ وارد صندوق ارتباط شوید، وضعیت را تغییر دهید و پاسخ یا یادداشت داخلی بنویسید. برای مقاله‌ها از پنل مجله استفاده کنید.

## داده‌های نمایشی

پروفایل متخصصان، هزینه‌ها و زمان‌های اولیه نمونه‌اند. اطلاعات مقاله‌ها در `mehregan-magazine-v1` و متخصصان، نوبت‌ها و پیام‌ها در `mehregan-operations-v1` در localStorage همین مرورگر نگهداری می‌شوند. اطلاعات بین دستگاه‌ها یا کاربران همگام نمی‌شوند؛ ورود امن، پرداخت، ارسال پیام و تماس ویدیویی واقعی در این نسخه وجود ندارد. پاسخ تیکت یادداشت محلی است و برای مخاطب ارسال نمی‌شود. پاک‌کردن داده سایت، داده‌های نمایشی را بازنشانی می‌کند.

در استقرار ایستا، مسیرهای برنامه باید به `index.html` بازنویسی شوند. فونت Vazirmatn از Google Fonts بارگیری می‌شود و Tahoma فونت جایگزین است. تنظیم کاهش حرکت سیستم رعایت می‌شود.
## طراحی و زبان رابط

ناوبری جدید شامل نوار باریک، مگامنوی برندها و مسیرهای مراقبت، جست‌وجوی برند و منوی موبایل است. صفحه اصلی با بنر اختصاصی مراقبت، رنگ قرمز و سفید، بلوک‌های روشن و پیش‌نمایش تعاملی هر پلتفرم بازطراحی شد.

تمام صفحه‌های عمومی، سایت‌های پلتفرم‌ها و پنل‌های مدیریت فقط فارسی و راست‌به‌چپ هستند. انتخاب زبان قبلی مرورگر اثری بر نمایش ندارد. تاریخ‌های تقویم با ماه‌های شمسی و هفته‌های شنبه تا جمعه نمایش داده می‌شوند.

ابزارهای قالب‌بندی فارسی در `src/i18n.ts` قرار دارند. تمام تصاویر فعال محلی هستند؛ شرح ساخت و کاربرد هر تصویر در `ASSETS.md` ثبت شده است.

## تازه‌ترین ویرایش رابط

- متن اعلان بالای بنر، زیرنویس روی بنر و برچسب «پیش‌نمایش تجربه دیجیتال» حذف شدند.
- لینک «مسیرهای مراقبت» از منوی اصلی حذف شد؛ «درباره ما» مستقیم صفحه خودش را باز می‌کند. منوی «مجله سلامت» دسته‌بندی‌های منتشرشده را نمایش می‌دهد و انتخاب هر دسته فیلتر مجله را فعال می‌کند.
- جست‌وجوی سراسری اکنون برندها، خدمات و مقاله‌های منتشرشده را با پیشنهادهای اولیه نشان می‌دهد.
- فوتر تیره است و مسیرهای پیام عمومی، معرفی متخصص و همکاری سازمانی را به فرم درست هدایت می‌کند. نشانی یا شماره تماس تأییدنشده در آن درج نشده است.
- موشن‌ها برای ورود محتوا، تغییر نوع فرم تماس، کارت‌ها و تغییر صفحه اضافه شده‌اند؛ تنظیم کاهش حرکت سیستم رعایت می‌شود.
- تصاویر بخش‌های معرفی، درباره ما، دنیای مهرگان و هدر هر سایت مستقل هستند. مقاله‌ها یک مجموعه تصویرسازی غیرواقع‌گرا و هماهنگ دارند؛ فایل‌ها در `public/images` نگهداری می‌شوند.


## تجربه رزرو و مدیریت

- چهار متخصص اولیه برای هر پلتفرم، با داده مشترک میان معرفی متخصصان، رزرو و مدیریت. ارتقای داده‌های قدیمی یک‌بار انجام می‌شود و سوابق قبلی حفظ می‌شوند.
- رزرو سه‌مرحله‌ای، با انتخاب متخصص و زمان، مشخصات مراجع و تأیید همراه کد پیگیری.
- تقویم هفتگی با ردیف‌های نیم‌ساعته و تقویم ماهانه شمسی؛ انتخاب روز و ساعت، فرم ایجاد وقت را پر می‌کند. نوبت‌های آزاد، رزروشده و غیرفعال متمایزند و جزئیات هر نوبت قابل مشاهده است.
- رنگ پنل هر مجموعه با سایت همان مجموعه هماهنگ است؛ مجله نیز از پوسته مشترک `OpsShell` استفاده می‌کند.
- تیترهای `##` و `###` در مقاله‌ها به عنوان h2 و h3 نمایش داده می‌شوند؛ فهرست مقاله با اسکرول به‌روز می‌شود. متن به صورت امن و بدون HTML خام رندر می‌شود.
- داده‌ها همچنان در localStorage همین مرورگر ذخیره می‌شوند؛ ارتباط سرور، ارسال پیامک و پرداخت به این نسخه اضافه نشده است.

بررسی منطق: `node tests/operations.test.mjs` و `node tests/calendar-articles.test.mjs` و `node tests/migration.test.mjs`.
